# FAYROZ Requests — V0.5 Lean Pricing History

تطبيق Android Native عربي RTL لإدخال كشوف طلبات الصنايعية لكل مشروع، وتسعير نفس البنود من أكثر من مورد، وبناء قاعدة أسعار تاريخية خفيفة وواضحة بدون تحميل البرنامج بوظائف غير لازمة.

## الفكرة المحورية

**الصنف (Item) هو قلب النظام.** الصنف يُسجل مرة واحدة، ثم يرتبط بالكشوف والكميات والاستخدامات وأسعار الموردين عبر الزمن.

المسار اليومي المقصود يظل قصيرًا:

**مشروع → كشف → أصناف وكميات → تسعير من الموردين → مقارنة → حفظ / تصدير**

## المنفذ حتى V0.5

### المشروعات والكشوف
- إدارة المشروعات: إضافة / تعديل / حذف.
- إنشاء وتعديل وحذف كشف طلبات مرتبط بمشروع.
- ترقيم مقترح تلقائي للكشوف داخل كل مشروع.
- بنود الكشف: الصنف، الكمية، الوحدة، الاستخدام/مكان الاستخدام، الوصف.
- إنشاء الصنف تلقائيًا من الكشف إذا لم يكن موجودًا.
- بحث في الكشوف وقاعدة الأصناف.

### الموردون وقوائم الأسعار
- إضافة / تعديل / حذف مورد.
- مورد معتمد / غير معتمد.
- نسبة خصم افتراضية للمورد.
- أكثر من قائمة أسعار مؤرخة لكل مورد.
- حفظ سعر الليستة + الخصم المطبق + السعر الصافي تاريخيًا.
- خصم خاص للصنف مع أولوية على خصم المورد العام.
- عروض سعر مباشرة تدخل التاريخ السعري بدون تلويث الليستات الرسمية.

### تسعير الكشوف
- مقارنة أسعار نفس بنود الكشف من أكثر من مورد.
- أحدث سعر محفوظ لكل مورد/صنف.
- أقل صافي للوحدة وإجمالي البند.
- إجمالي المورد ونسبة تغطية بنود الكشف.
- أقل تجميعة شراء من أقل سعر لكل بند.

### استيراد Excel / CSV
- استيراد قوائم الأسعار من XLSX وCSV.
- اكتشاف صف العناوين تلقائيًا حتى لو سبقه عنوان أو مقدمة.
- ربط أعمدة الملف يدويًا قبل الاستيراد.
- مطابقة الأصناف بالكود ثم الاسم الموحّد ثم اقتراح تشابه.
- مراجعة الأصناف غير المحسومة قبل الحفظ.
- ربط بصنف موجود / إنشاء صنف جديد / تخطي.
- استخدام خصم الملف عند وجوده، وإلا خصم المورد/الصنف المحفوظ.
- Upsert داخل نفس الليستة لمنع التكرار.
- حفظ اسم ملف المورد كمصدر للقائمة.
- ملف `IMPORT_TEMPLATE.csv` كنموذج جاهز.

### جديد V0.5 — بدون حشو

#### 1) تاريخ سعر الصنف
من شاشة **قاعدة الأصناف** اضغط على أي صنف لعرض:
- كل الأسعار السابقة مرتبة من الأحدث للأقدم.
- اسم المورد.
- اسم الليستة إن وجد.
- سعر الليستة.
- الخصم الذي طُبّق وقتها.
- السعر الصافي.
- تاريخ السعر ومصدره.

#### 2) حداثة السعر Price Freshness
يظهر بجوار السعر وصف بسيط يساعد في عدم الاعتماد على سعر قديم:
- حتى 30 يوم: **حديث**.
- من 31 إلى 90 يوم: **يحتاج مراجعة**.
- أكثر من 90 يوم: **قديم**.

المؤشر يظهر في تاريخ الصنف وفي شاشة مقارنة أسعار الكشف.

#### 3) تصدير كشف التسعير
من شاشة تسعير الكشف:
- تصدير **PDF** بسيط ومرتب.
- تصدير **Excel XLSX** عربي RTL.
- التصدير يشمل المشروع، رقم الكشف، البنود، أفضل سعر لكل بند، الخصم، الصافي، إجمالي البند، تاريخ السعر، وملخص الموردين.
- التصدير مبني بأدوات Android / ZIP XML مباشرة بدون مكتبات Excel أو PDF ضخمة.

## التحقق

- تم الحفاظ على اختبارات Parser/Matcher الخاصة بـ CSV وXLSX من V0.4.
- تمت إضافة اختبار لمنطق Price Freshness.
- تم التحقق من بنية XLSX المستخدمة في التصدير باستخدام قارئ OpenXML متوافق.
- بيئة الإنشاء الحالية لا تحتوي Android SDK كامل، لذلك لم يتم إنتاج APK أو تنفيذ Android Gradle Build كامل داخل هذه البيئة.

## فتح المشروع

افتح المجلد في Android Studio ثم:
1. Gradle Sync.
2. تأكد من JDK 17 أو المتوافق مع Android Gradle Plugin المستخدم.
3. Run على Emulator أو جهاز Android.
